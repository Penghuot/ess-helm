## 🎯 **What Could Go Wrong? (And How We Handle It)**

### Scenario 1: Typo in Environment Variable
**Prevention:** Copy-paste from DEPLOY-NOW.md  
**Detection:** Service won't start, error in logs  
**Fix:** Edit variable in Railway, service auto-restarts  
**Time to fix:** 2 minutes

### Scenario 2: Database Connection Fails
**Prevention:** Use Railway service references `${{db.VAR}}`  
**Detection:** Service crash loop, "connection refused" in logs  
**Fix:** Verify database is green, check variable names  
**Time to fix:** 2 minutes

### Scenario 3: MAS/Synapse URL Mismatch
**Prevention:** Deploy MAS first, copy URL carefully  
**Detection:** OAuth redirect fails, "invalid redirect_uri"  
**Fix:** Update MAS_CLIENT_REDIRECT_URI to match Synapse URL  
**Time to fix:** 1 minute

### Scenario 4: Signing Key Format Wrong
**Prevention:** Copy entire PEM including headers  
**Detection:** MAS won't start, "invalid key" in logs  
**Fix:** Re-paste key ensuring newlines preserved  
**Time to fix:** 2 minutes

**All scenarios covered in [VERIFICATION.md](VERIFICATION.md) troubleshooting!**
